Prove, on every test run and before every deploy, that the giftee cannot learn a discussion exists, and make person deletion and the operator docs cover discussions.

Purpose: DISC-04 (D-05) and D-07. This plan adds no feature. It extends the Phase 3 secrecy suite to the discussion data and routes built in 05-01 and 05-02, and fixes any real leak the suite finds.
Output: discussion data in the fixture, new detectors and tests (English and Czech), `delete_user` coverage for comments, DEPLOYMENT.md updates.
</objective>

Locked decisions (ROADMAP Phase 5 Notes, 2026-11-14), numbering as in 05-01 and 05-02:
- D-05: the giftee never learns a thread or comment exists, through any page, count, marker, URL, POST response or admin view; comment text joins the secrecy suite's sentinels; the proof covers the giftee who is also a giver in the same event and a staff giftee.
- D-07: `delete_user` covers comments.
- D-08: Czech for everything user-facing; the Czech pass of the suite is part of this.
