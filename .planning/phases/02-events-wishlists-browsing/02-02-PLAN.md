## Phase Goal

> ROADMAP `**Goal:**` (verbatim, not in user-story format): "Signed-in users can create an event, invite family with a link, keep a personal wishlist, choose which wishes to share into which events, and browse what the other members wish for." No user story is invented; run `/gsd-mvp-phase 2` if one is wanted.

## Assumption-delta decision

<assumption_delta_decision>
Signal "chosen" (the user chooses which wishes go into which events). Primary noun: the explicit share link between a Wish and an Event (the `Wish.events` M2M). It is the only way a wish becomes visible to anyone else. Decision: promote. There is no "visible in all my events" flag and no implicit default visibility; the new-wish pre-tick (D-10) and Share all (D-11) just create share rows. Invariant test, added in Task 1: a wish that is not shared into an event never appears on that event's page for any other member, even when its owner is a member there.
(The "fallback" and "optional" signals are recorded in plan 02-01.)
</assumption_delta_decision>
