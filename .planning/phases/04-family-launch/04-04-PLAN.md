# Plan 04-04: Phone pass on stock Bootstrap

## Phase Goal

> ROADMAP `**Goal:**` (verbatim, not in user-story format): "Czech- and English-speaking relatives can use Gifter comfortably on their phones, the data is safely backed up, and a real family dry-run has passed before the 1 Dec freeze." No user story is invented here. Run `/gsd-mvp-phase 4` if you want one.

This plan delivers the phone half of the goal (I18N-02, ROADMAP SC2) in code and tests. It runs in wave 3 after plan 04-01 (EN / CS switch in base.html, complete Czech catalogue) and plan 04-03 (`id="own-wishes"` in event_detail.html, Czech secrecy pass), next to plan 04-05 (health check, launch hardening, dry-run kit), with which it shares no file. Real-device checks are end-of-phase human checks listed in 04-05's dry-run kit, not checkpoints. Nothing is pushed or deployed by this plan.

<objective>
Make every page comfortable on a phone without leaving stock Bootstrap: 44px tap targets, stacked full-width action buttons below 576px, wrapping text and rows, no fixed widths, all pinned by tests that also run in Czech.

Purpose: relatives open Gifter from a chat app on their phones; the dry-run with 2-3 of them must happen by ~22 Nov, and the Czech catalogue and phone pass should be ready before the window opens (~15 Nov).
Output: gifter.css linked from base.html, button groups and wrapping rows in the templates, test_phone.py.
</objective>
