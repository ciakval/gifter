# Plan 04-01: Czech everywhere, with an EN / CS switch

## Phase Goal

> ROADMAP `**Goal:**` (verbatim, not in user-story format): "Czech- and English-speaking relatives can use Gifter comfortably on their phones, the data is safely backed up, and a real family dry-run has passed before the 1 Dec freeze." No user story is invented here. Run `/gsd-mvp-phase 4` if you want one.

This plan delivers the language half of the goal (I18N-01) up to the privacy page. Plan 04-02 (backups, same wave 1), plan 04-03 (privacy policy and the secrecy suite in Czech, wave 2), plan 04-04 (phone pass, wave 3) and plan 04-05 (health check, launch hardening, dry-run kit, wave 3) deliver the rest. User priority is "usable asap": no checkpoints, nothing pushed or deployed by this plan. Do not push main between this plan and the end of plan 04-03: the policy text for the language cookie and the Czech secrecy pass land there.

<objective>
Make every page of Gifter read naturally in Czech for Czech browsers, give everyone an EN / CS switch, and make CI refuse an incomplete or stale Czech catalogue.

Purpose: relatives are mostly Czech speakers on phones and open Gifter from a chat app; Czech must be the default for them and one tap away for everyone else.
Output: set_language route and switch, complete Czech catalogue (.po plus committed .mo), catalogue gate in CI, Czech plural tests, Czech landing check in the container smoke.
</objective>

Planner-verified at HEAD cce7779 (Django 6.1.2, gettext-tools 1.0 and sqlite3 3.53 on the dev box; scratch copies only, nothing in the repo changed):
- `django.views.i18n.set_language`: reads `next` from POST (or GET), falls back to the Referer, then to "/" when the target is not a safe same-host URL. Only a POST sets the cookie, and only for a `language` value that passes `check_for_language`. It uses `LANGUAGE_COOKIE_NAME/AGE/PATH/DOMAIN/SECURE/HTTPONLY/SAMESITE`. It has no `login_required` attribute, so `LoginRequiredMiddleware` would redirect anonymous visitors: wrap it with `login_not_required` in web/urls.py (that decorator only sets an attribute on the function).
- `LocaleMiddleware` is already installed between SessionMiddleware and CommonMiddleware. Resolution order: language cookie, then Accept-Language, then `settings.LANGUAGE_CODE` ("en"). The Django test client sends no Accept-Language, so `override_settings(LANGUAGE_CODE="cs")` makes every request in a test class render Czech. Django's test signal handler resets the translation caches when LANGUAGE_CODE changes.
- web/settings.py: `LANGUAGES = [("en", "English"), ("cs", _("Čeština"))]`, `LOCALE_PATHS = [BASE_DIR / "locale"]` (the directory does not exist yet), `TIME_ZONE = "Europe/Prague"`. No LANGUAGE_COOKIE_* settings. The production block (`if not DEBUG:`) sets SESSION_COOKIE_SECURE and CSRF_COOKIE_SECURE. TEMPLATES context processors are debug, request, auth, messages: there is no i18n processor, so `{{ LANGUAGE_CODE|default:'en' }}` in base.html line 2 always renders "en".
- base.html: the navbar shows links and a POST sign-out form inside `#gifter-nav` only for signed-in users; the footer holds only the Privacy policy link. Every app page and the allauth pages extend it.
- `makemessages -l cs` on a scratch copy finds 172 msgids, 2 of them plural ("%(counter)s member" in event_detail.html and invite.html; "%(count)d wish is shared here now." in views.event_share_all). English source text totals about 1,330 words, most of it on the privacy page. Two "message contains an embedded URL" warnings (forms.py line 58 and the privacy page's Google link) are harmless. A newly generated .po has a `#, fuzzy` header and a Plural-Forms line copied from Django's own cs catalogue: `nplurals=4; plural=(n == 1 && n % 1 == 0) ? 0 : (n >= 2 && n <= 4 && n % 1 == 0) ? 1: (n % 1 != 0 ) ? 2 : 3;`. A fuzzy header is dropped by msgfmt, which silently loses Plural-Forms.
- `gettext.c2py` on Django's expression and on the three-form expression: for every n in 0..1000 the three-form index equals {0:0, 1:1, 3:2}[Django index], and Django's index 2 never occurs for integers. Django's Czech catalogue gives `ngettext("%(num)d minute", "%(num)d minutes", n)`: "1 minuta", "2 minuty", "5 minut". Django 6.1 keeps catalogues with different plural equations apart (`trans_real.TranslationCatalog`), and the LOCALE_PATHS catalogue is searched first.
- `compilemessages` walks the whole tree including `.venv` unless given `--ignore=.venv`. `makemessages` ignores dot-directories by default; add `--ignore=staticfiles --ignore=data` for local leftovers.
- `msgattrib --untranslated --no-obsolete FILE` and `msgattrib --only-fuzzy --no-obsolete FILE` print nothing when nothing matches, and print the header plus the entries otherwise. `msgfmt --check` also validates python-format placeholders and the plural count against the header.
- Tests that inspect forms: test_inapp.py line 120 asserts that the in-app landing contains no `<form` at all (written before any footer form existed). test_auth.LandingTests takes the first POST form on the landing page, which stays Google's because the footer comes after `<main>`.
- Routes whose view has `login_required = False` (computed over the full resolver walk, 63 routes): "", "privacy/", "invite/<slug:token>/", "accounts/login/", "accounts/logout/", "accounts/3rdparty/login/cancelled/", "accounts/3rdparty/signup/", "accounts/google/login/", "accounts/google/login/callback/", "gifter-admin/login/" (the top-level redirect and the admin's own shadowed login share this string). No test pins this set yet; test_lockdown pins only the accounts/ routes.
- test_secrecy.py: `RouteGuardTests.test_every_walked_route_has_a_probe` fails for any new route without a probe in `probes(fx)`. The full suite (264 tests) runs in about 7 seconds. The Czech rerun of the suite, the own-wish region by id and the Czech claim-state markers belong to plan 04-03.
- Parallel worktree in the same wave: plan 04-02 runs its own container smoke with `SMOKE_TAG=smoke-0402 SMOKE_PORT=18102` (a different image tag, container names and port) and a backup smoke on its own image tag with no published port, so this plan's `bash scripts/container-smoke.sh` (default tag and port 18000) cannot race with it.
- Never use `_` as a throwaway name in modules or tests that import `gettext as _`.
