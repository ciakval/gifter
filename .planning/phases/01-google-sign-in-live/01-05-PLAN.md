## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| user → server .env / GitHub secrets | Production secrets are created and stored by the user |
| Google → Gifter callback | Google only redirects to registered URIs |
| CI → shared Bombur host | Deploy key grants a docker-group (root-equivalent) user |

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |

| T-01-24 | Information disclosure | SECRET_KEY, Google client secret | high | mitigate | Task 1 tells the user to type secrets directly into the server .env (chmod 600) and never into chat, repo or GitHub; the app refuses to start with an empty SECRET_KEY or empty Google values (plan 01-01) |
