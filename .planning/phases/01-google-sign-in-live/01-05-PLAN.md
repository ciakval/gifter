## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| user → server .env / GitHub secrets | Production secrets are created and stored by the user |
| Google → Gifter callback | Google only redirects to registered URIs |
| CI → shared Bombur host | Deploy key reaches the deploy user, but only via the forced command `bombur-deploy gifter` (no shell, no file copy) |
| Caddy site files → every site on Bombur | A broken site file can stop Caddy reloading for all apps |
